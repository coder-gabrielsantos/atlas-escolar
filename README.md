# Atlas — Next.js

Nova implementação do Atlas Escolar em Next.js 16, com App Router, TypeScript, Tailwind CSS e Recharts.

## Executar localmente

```bash
npm install
npm run dev
```

A aplicação fica disponível em `http://localhost:3000`.

## Funcionalidades

- filtros compartilhados por estado, município, escola e perfil de acesso;
- comparação opcional com a média municipal;
- indicadores, diagnóstico detalhado e gráficos responsivos;
- assistente contextual com sugestões, histórico, fontes e visualizações;
- plano de ação com checklist persistido no navegador;
- relatório em PDF gerado a partir do contexto atual;
- navegação responsiva para desktop e dispositivos móveis;
- ferramenta WebMCP para selecionar o contexto escolar;
- metadados Open Graph e cartão social próprio.

Os dados incluídos são sintéticos e servem exclusivamente para demonstração.
